# MaiChat website

The static website for [maichat.me](https://maichat.me/), hosted with GitHub Pages
from the root of the `main` branch in `macareli/macareli.github.io`.

The MaiChat application is maintained in
[macareli/Maichat](https://github.com/macareli/Maichat).

Edit `index.html` to update the page. No build step or dependencies are required.
Keep `CNAME` set to `maichat.me` so future deployments retain the custom domain.
