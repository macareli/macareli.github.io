# Native Android screenshot provenance

Captured on 2026-11-19 in the public MaiChat **1.19.4** Android app, in Dark mode. The four PNGs below are fresh, unaltered native Android screenshots, each **1440 × 3120 pixels** at 480 dpi. They were captured from actual taps, scrolling, catalogue downloads and Android image-picker use. They are not enlarged copies of earlier screenshots.

No application state was injected, no preferences were seeded, and no widget-test rendering, fixture catalogue, generated placeholder artwork or constructed assistant replies were used. The app was installed into a separate Android environment so the pre-existing installation and its data could be preserved. No chat provider was configured.

| File | Actual screen and workflow |
| --- | --- |
| `chat.png` | Downloaded **Journey of Elaina, wandering witch** by **Aithen** from live Discover → Chub. Opened a new chat and selected the card's second bundled greeting. Applied the built-in Roleplay look to this chat and imported a real mountain photograph through Edit Chat → Custom background → Files → Android Gallery. Scrolled to the beginning of the greeting. The visible text belongs to the downloaded card; it is not a newly generated reply. |
| `studio.png` | Opened that downloaded Elaina card through Characters → Open in Studio, then Actions → Other areas → Draft. Its portrait, tags and fields are the actual imported card. No agent run or staged draft was created. |
| `discover.png` | Live Chub results for **journey**, with adult content disabled. Visible entries include Journey Through The Youkai Mountain, Journey of Elaina, Frieren: Beyond Journey's End and The Unlikely Journey. |
| `home.png` | Created a separate Home page with the real Home editor. Added the actual Elaina chat with its portrait as the card background, a character row, and Studio, Library, Discover and Gallery shortcuts. The second character, **Frieren: Beyond Journey's End** by **CassandraZX**, was downloaded through Discover along with its attached lorebook. Earlier Home pages were retained. |

The chat wallpaper is an unchanged downloaded mountain-valley photograph from [Unsplash](https://images.unsplash.com/photo-1464822759023-fed622ff2c3b?auto=format&fit=crop&w=1600&q=90), imported through Android's normal image picker. Character artwork and card text came from the live catalogue downloads above.

Android's standard status-bar demo controls fixed the clock, and the unavailable battery icon was hidden through Android settings before capture. The original PNG pixels were not retouched. Display and system-UI overrides were restored afterward, and both capture environments were stopped. The pre-existing environment was restored to its original 1080 × 2340 display and 420 dpi.

These Android 12 software-rendered captures demonstrate the app's screens and content. They do not establish physical-device smoothness or Android performance. No Dart runtime was attached: the official Dart MCP connection search found no running DTD/debug process for the release app, so navigation used native Android input.
